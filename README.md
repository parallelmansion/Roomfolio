# Roomfolio

作者の世界を「部屋」として体験させながら、  
その裏側で活動情報を「索引」として整理し続ける、  
次世代のクリエイターポートフォリオです。  
Roomfolio が「見せ方」、Index が「整理の仕組み」を担います。 0 1

## Concept

Roomfolio Gen_2 は、作品をただ並べるための場所ではありません。  
訪れた人が作者の空気感や居場所を感じながら歩き、作品へ辿り着き、  
作者全体の活動まで自然に理解できる導線をつくります。 2

一方で Index は、流れて消えやすい SNS の弱点を補い、  
プロフィール、活動年表、作品一覧、外部リンクをひとつに束ねる整理エンジンです。 3

## What Roomfolio Gen_2 does

- 作者の世界観を空間として見せる
- 作品を「部屋の中の体験」として見せる
- 活動履歴や作品情報を整理する
- 初見の人が作者全体を短時間でつかめるようにする
- 作品から作者へ、作者から次の作品へつなげる

## Role Split

### Roomfolio
- 表側の体験
- 部屋、光、家具、音、導線
- 作品へ入っていくための空間

### Index
- 裏側の整理
- プロフィール、年表、作品一覧、タグ、外部リンク
- Roomfolio の中身を支える情報基盤

## Philosophy

- 装飾より導線
- 投稿より蓄積
- 作品単体より作者全体
- 一覧より輪郭
- 体験と整理を分けずに重ねる

## Goal

初めて来た人にも、  
「この作者は何を作っていて、どんな活動をしているのか」がすぐ伝わること。  
そして、興味を持った人がそのまま部屋の奥へ進み、  
作品を見て、作者を知って、次の作品へ辿り着けること。 4

## In short

**Roomfolio Gen_2 は、作者の世界を歩けるようにしながら、その活動を見失わないための、居場所つきの索引です。**



Roomfolio Gen_2 はクリエイターポートフォリオとして始まりますが、将来的には誰でも自分だけの部屋を作り、公開・保存・交流できるプラットフォームへ発展することを目指しています。
