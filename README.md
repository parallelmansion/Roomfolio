# Roomfolio

Roomfolioは、
作者のプロフィールを「部屋」として表現するサービスです。

家具を通して作品やSNS、Webサイトなどへ自然につながり、
作者全体をひとつの空間として体験できます。

---

## コンセプト

- 部屋がプロフィールになる
- 家具がコンテンツへの入口になる
- 作者と出会う体験をつくる

---

## このリポジトリについて

このリポジトリでは、Roomfolioの設計・実装を行います。
